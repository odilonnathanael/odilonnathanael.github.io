Cette semaine, j'ai installé tous les outils nécessaires pour créer mon site personnel :

- Ruby et Jekyll sur Fedora
- Git pour la gestion de version
- VS Code comme éditeur de code

J'ai également configuré GitHub Pages et mon site est maintenant accessible à l'adresse https://odilonnathanael.github.io.

Les principales étapes ont été :
1. Installation de Ruby et Jekyll
2. Création du site avec jekyll new
3. Configuration du fichier _config.yml
4. Test en local avec bundle exec jekyll serve
5. Mise en ligne sur GitHub
