Cette semaine, j'ai ajouté une section "Projets" sur mon site pour présenter mes réalisations personnelles.

## Pourquoi une page projets ?

- Présenter son travail de manière structurée
- Montrer ses compétences techniques
- Faciliter le recrutement ou les collaborations

## Structure d'un projet type

1. Nom du projet : titre accrocheur
2. Description : objectif, contexte, difficultés rencontrées
3. Technologies : stack utilisée
4. Lien : vers le dépôt GitHub ou la démo

Chaque projet est une occasion d'apprendre et de démontrer ses capacités.
