## What is CI/CD?

CI (Continuous Integration): developers frequently merge their changes into a shared repository. Each integration is verified by an automated build and tests.

CD (Continuous Deployment): validated changes are automatically deployed to production.

## Common tools

- GitHub Actions: integrated with GitHub
- Jenkins: open source and highly configurable
- GitLab CI: integrated with GitLab
- CircleCI: cloud-based

## Benefits

- Early bug detection
- Faster delivery
- Reduced risks
- Process automation

CI/CD has become a standard in modern development.
