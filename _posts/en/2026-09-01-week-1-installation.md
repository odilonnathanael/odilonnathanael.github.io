This week, I installed all the tools needed to create my personal website:

- Ruby and Jekyll on Fedora
- Git for version control
- VS Code as code editor

I also configured GitHub Pages and my site is now available at https://odilonnathanael.github.io.

The main steps were:
1. Installing Ruby and Jekyll
2. Creating the site with jekyll new
3. Configuring the _config.yml file
4. Testing locally with bundle exec jekyll serve
5. Publishing on GitHub
