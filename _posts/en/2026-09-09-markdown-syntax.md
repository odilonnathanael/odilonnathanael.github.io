Markdown is a lightweight markup language created by John Gruber. It makes writing formatted text easy.

## Headings

# Heading 1
## Heading 2
### Heading 3

## Formatting

- *italic* or _italic_
- **bold** or __bold__
- ***bold italic***
- ~~strikethrough~~

## Lists

- Item 1
- Item 2
  - Sub-item A
  - Sub-item B

## Links and images

[Link text](https://example.com)
![Alt text](image.jpg)

## Inline code

Use backticks: `code`

## Tables

| Column 1 | Column 2 |
|----------|----------|
| Value A  | Value B  |
| Value C  | Value D  |

Markdown is used on GitHub, blogs, documentation, etc.
